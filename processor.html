Multicore Processor

Pipelined, 2-way Cache


Implementation/RTL


Design

The Processor features 2 cores with a master-slave scheme that communicate with a custom handshake protocol. Each core has a 4-stage pipeline with dataforwarding to resolve hazards. Data and Program memory are implemented with 2-way Cache. Test programs are converted to machine code through a custom assembler.
