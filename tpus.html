TPU 2

TPU 2 uses systolic execution to perform matrix-matrix multiplicaiton. The systolic array is implemented as an AXI peripheral in a Microblaze system and testing using a Nexys DDR board. The array has a control unit that determines the minimum of cycles necessary to complete multiplicaiton using the dimensions of the operand matricies.

TPU 1

TPU 1 features matrix-vector multiplicaiton acceleration using a VLIW scheme. A very bare custom RISC processor uses one of its register files as a pointer to memory, which the accelerator uses to fetch data to store in its local storage. The accelerator peforms multiplicaiton and can apply a ReLU activation function. The following pdf gives more details about the design and testing scheme.
